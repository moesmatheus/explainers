## 0. The Spine (every card serves this single through-line)

> A PDE is a **local conversation between a point and its neighbors**. The **Laplacian** Δu — "the average of my neighbors, minus me" — is the **grammar**. The big three are the SAME spatial operator wired to time three ways: **HEAT** uₜ = Δu relaxes TOWARD the neighbor-average (smoothing, irreversible, an arrow of time); **WAVE** uₜₜ = Δu ACCELERATES toward it (overshoot → ringing forever, finite speed, reversible, energy-conserving); **LAPLACE** Δu = 0 means you ARE the neighbor-average (equilibrium, the smoothest field). **FOURIER** is the language that makes it trivial: sines are eigenfunctions of Δ (Δ sin kx = −k² sin kx), so the PDE splits into one independent ODE per mode — heat kills high modes fastest (e^{−k²t}), waves spin each at its own pitch (cos kt), Laplace freezes them. Separation of variables, "hear the shape of a drum", spectral methods, and von Neumann stability are ALL this one idea. The closer flips the operator's character: coupled nonlinearly with unequal diffusion, the *smoothing* operator *builds* Turing patterns.

**Anchor cards (5, marked with ★ spine):** `laplacian` (the grammar), `bigthree` (the payoff — one operator, three fates), `fourier` (the language — diagonalize Δ), `cfl` (the same Fourier mode that solves heat governs stability), `turing` (the operator's character flips — closer). These are exactly the five already flagged `anchor` in `SECTIONS` and the stubs. **Through-line confirmed: every one of the 21 cards routes back to Δ and/or Fourier** (see §3 traceability table).

## 1. Numerical-risk register (prioritized) — the exact verified constants

These are the things most likely to **silently break** in the build. Hard-code the verified constants; never let a slider's default land outside the stable region.

**RISK 1 — Heat FTCS blows up if r > ½ (1D) / > ¼ (2D).** The single most common failure.
- 1D (bigthree, fourier-compare, cfl, gallery-BS-morph): `r = ν·dt/dx² ≤ 0.5`. **Defaults: HEAT_R = 0.40** (bigthree), `r=0.4` (fourier direct-compare), `r=0.30` (gallery morph). Verified: r=0.50 marginal, **r=0.51 diverges (step 383)**.
- 2D (heat plate, laplacian relax): the operative bound is **r ≤ ¼** (NOT 4r<1 — see C2 correction). Heat plate: `D=0.2, dt=1, dx=1 → r=0.2 ≤ ¼`. Laplacian/Laplace relax in unnormalized form `u += α(neighborSum−4u)`: **α ≤ ¼**; **default ALPHA = 0.20**. Verified: α=0.25 marginal (checkerboard stalls), **α=0.26 diverges (~step 189–250)**.
- **Slider trap:** the laplacian α-slider range is `[0.05, 0.30]` and the cfl r-slider is `[0.1, 0.75]` — both deliberately cross the ceiling so the reader can trigger the checkerboard. **Must auto-reset on blow-up** (scan max|u| every frame, reseed if >1e6 or non-finite). Cap the laplacian *convergence* demo at α≤0.24; reserve 0.25–0.30 for the "watch it stall/erupt" demo only.

**RISK 2 — Wave leapfrog needs Courant C ≤ 1 AND the correct from-rest first step.** C=0.70 default. Verified: C=1.00 marginal, **C=1.0001 diverges**. **First step MUST be the second-order Taylor half-step** `u¹ᵢ = u⁰ᵢ + ½C²(u⁰ᵢ₊₁ − 2u⁰ᵢ + u⁰ᵢ₋₁)` — NOT `u_old = u`. With the wrong start the d'Alembert overlay error is 1.7e-2 (visible mismatch) and the "exact at λ=1" claim is false; with the right start it is machine-exact at C=1 and 1.2e-3 at C=0.5. **(C3 correction — was a blocker, now resolved here.)** Thereafter: `uⁿ⁺¹ᵢ = 2uⁿᵢ − uⁿ⁻¹ᵢ + C²(uⁿᵢ₊₁ − 2uⁿᵢ + uⁿᵢ₋₁)`.

**RISK 3 — Advection must be UPWIND, never centered.** Linear transport (characteristics): `u_new[i] = u[i] − ν(u[i] − u[i−1])`, `0 < ν ≤ 1`, **ν=0.8**. Centered explicit advection is unconditionally unstable (verified: 4e26). Burgers: conservative flux form on f=u²/2 (Engquist–Osher or Godunov), `dt = CFL·dx/max|u|`, **CFL=0.4**, and when viscosity ν>0 add the **parabolic cap** `dt ≤ 0.25·dx²/ν` (verified: violating it blows up at iter 33).

**RISK 4 — NAVIER–STOKES: do NOT draw a −5/3 reference line on the measured 64² spectrum.** This is the only outright false visual claim across all clusters. On 64² there are ~10 usable wavenumbers; measured slope is −7…−14 (proposed params) or ~−2.5 (weak dissipation), never −5/3. **(C6 correction — was a blocker.)** Resolution baked into §2: present the −5/3 (and −3) as a **schematic/idealized cartoon clearly separated from the live curve**, label "idealized cascade — too few decades on a 64² grid for a clean fit", restrict any fitted window to k=2..10, and **time-average E(k)** (EMA) before plotting. The solver itself is verified stable & cheap (0.7 ms/frame).

**RISK 5 — GRAY-SCOTT dt hard ceiling.** `Du=0.16, Dv=0.08, dt=1.0` → `Du·4·dt=0.64<1` stable. **Hard-clamp any user dt/step-rate so effective dt ≤ 1.5** (dt≥2.0 → NaN, verified). Seed noise ≤ 0.01. Clamp the (F,k) phase-pad pin to `F∈[0.01,0.06], k∈[0.045,0.07]` (outside → blank canvas that looks broken, not a crash).

**RISK 6 — Black–Scholes → heat needs the σ²/2 time rescale.** **(C6 correction.)** State `τ = (σ²/2)(T − t)` consistently in the headline, predict-reveal, AND deeper — NOT `τ = T − t` (residual 1.5e-1, wrong). With `α=−(k−1)/2, β=−(k+1)²/4, k=2r/σ²` and the rescale, residual is 1.5e-7. (Alternative if narrative simplicity wanted: keep τ=T−t but then the equation is `u_τ = (σ²/2)u_xx`.)

**RISK 7 — Characteristics worked-example numbers were wrong.** **(C3 correction.)** For `u0 = 1 + 0.5 exp(−((x−0.4)/0.08)²)`: `min(u0') = −5.36` (not −4.6), `t* = 0.187` (not 0.22). Use −5.36 / 0.187.

**RISK 8 — Laplace iteration counts are grid-dependent.** **(C4 correction.)** The live plate is N=60 → Jacobi ~4739, GS ~2617 (1.81×), center 0.2424. The pretty figures 2410/1315/0.2395 are the N=40 reference. **Pick ONE: standardize all prose on N=60** (Jacobi ~4739, GS ~2617, ~1.8× faster, center ≈0.242). Continuous-exact center = 0.25.

**RISK 9 — whatis "single bump" mismatch.** **(C1 correction.)** The 4-cosine precomputed surface is a wrinkly multi-bump profile, not a single bump, and has Neumann (zero-slope) ends. **Reword predict-reveal to "a wrinkly profile (a few bumps and dips) → the wrinkles spread and smooth out"** and caption it "profile of a rod" (not "pinned rod").

**RISK 10 — Gibbs phrasing.** **(C4 correction.)** Say "**~8.95% of the jump** above the limiting value" (partial sum reaches ~1.0895× the full jump). Drop "1.0895× the half-jump".

### 01 · `whatis` — What is a PDE? · *Not a number through time — a whole shape through space and time* · **indigo** · not anchor
- **Insight:** an ODE follows ONE quantity (a dot on a line); a PDE follows an ENTIRE shape — every point evolving at once. Unknown is a field u(x,t). A partial derivative = "change if I wiggle one variable and freeze the rest."
- **Headline:** `\text{ODE: } \frac{d\uu{y}}{dt}=f(\uu{y},t)` · `\text{PDE: } \uu{u}_{\tt{t}}=f(\uu{u},\uu{u}_{\kx{x}},\uu{u}_{\kx{xx}},\dots)` · `\uu{u}_{\tt{t}}\equiv\partial\uu{u}/\partial\tt{t}|_{x},\ \uu{u}_{\kx{x}}\equiv\partial\uu{u}/\partial\kx{x}|_{t}`.
- **Interactive — "ODE→PDE morph + the u(x,t) surface with two slices":** Left panel segmented toggle ODE↔PDE. ODE: a dot slides a value-axis leaving a (t,y) trail. PDE: a 64-node rod (`Field1D` or `Heatmap2D` 64×1, `CM_DIVERGING`) whose profile ripples. Right panel: the precomputed u(x,t) on a **64(x)×64(t)** grid as a `Heatmap2D` with two draggable guide lines (vertical = `u(x₀,t)` time-series in orange; horizontal = `u(x,t₀)` spatial profile in cyan); slopes labelled live = uₜ, uₓ via central difference on the grid.
- **Verified scheme (PRECOMPUTED, not stepped):** `u(x,t)=Σ_{k=1..4} a_k e^{−(kπ)²νt} cos(kπx+φ_k)`, `ν=0.12, a=[1,0.5,0.35,0.2], φ=[0,1.1,2.3,0.7]`, `x∈[0,1], t∈[0,0.06]`, color clamp `[−1.2,1.2]` (actual range [−0.77,1.15]). Exact heat solution (foreshadows spine). ODE dot = table lookup `y(t)=u(x₀,t)`. Clock = 1 grid-row/frame via `useRaf`, looping. O(64·64) on build → instant.
- **Predict (CORRECTED):** "The rod starts as a **wrinkly profile (a few bumps and dips)**. As time runs, does it (a) fade uniformly, (b) **spread out and smooth/flatten**, (c) split and travel?" → **(b)** the wrinkles spread and smooth out, profile flattens (high/low mode amplitude ratio drops 0.20→0.069, ~3× wrinkle suppression). Swapping uₜ→uₜₜ would instead make it SPLIT (→ `bigthree`).
- **Misconception:** "A PDE is just an ODE with more variables." → No: ODE state is finite-dim (point in ℝⁿ); PDE state is a whole function (∞-dim) and is undetermined until you ALSO give **boundary** conditions in space, not just an initial condition. Why: the unknown lives in a function space; "where the field is pinned at the edges" is part of the problem.
- **Worked:** `u=e^{−π²t}sin(πx)` on [0,1]. Freeze x=½ → `e^{−π²t}` (an ODE you know). Freeze t=0 → `sin(πx)` (a shape). `uₜ=uₓₓ=−π²e^{−π²t}sin(πx)` — equal! You've verified it solves the heat equation.
- **Deeper:** order/linearity/homogeneous vocabulary; the independent-variable split (time deriv coupled to SPACE derivs = the neighbor-coupling = Δ, next card); Hadamard well-posedness & data-type differences; subscript notation, Δu=uₓₓ (1D)/uₓₓ+u_yy (2D), normalize constants to 1 (matches g=L=1 of the ODEs sibling).
- **Cross-links:** `laplacian`, `bigthree`. **Glossary:** field, partial derivative, well-posed, boundary condition, initial condition (all in GLOSS).

### 02 · `laplacian` — The Laplacian: your neighbors minus you · *One operator runs every PDE here — and it's just an average* · **indigo** · ★ ANCHOR
- **Insight:** Δu = (average of immediate neighbors) − you. Valley → Δu>0 (pulled up); peak → Δu<0 (pulled down); equal to average → Δu=0, nothing happens. The grammar of the whole explainer.
- **Headline:** `\lap{\Delta\uu{u}}\approx\overline{\uu{u}_{\text{neighbors}}}-\uu{u}` · `\text{1D: }\lap{\Delta\uu{u}}_i=\uu{u}_{i+1}+\uu{u}_{i-1}-2\uu{u}_i` · `\text{2D: }\lap{\Delta\uu{u}}_{ij}=\uu{u}_E+\uu{u}_W+\uu{u}_N+\uu{u}_S-4\uu{u}_{ij}`.
- **Interactive — "Hover-a-cell probe + one-button relax (this IS heat/Jacobi)":** 48×48 `Heatmap2D` `CM_DIVERGING`, seeded blobs (`mulberry32`). Hover → ring the 4 neighbors indigo, float a readout of the 4 values, their average, your value, Δu=(sum−4u) sign-colored (orange valley / cyan peak). PLAY "relax" → field blurs to flat harmonic equilibrium. 1D inset: wiggly curve colored by curvature sign. Reset restores blobs.
- **Verified scheme:** explicit Jacobi `u_new[i][j] = u + α(uE+uW+uN+uS−4u)`, **α=0.20** (default), fixed Dirichlet edges (pinned at seeded values → nontrivial harmonic limit). 2 steps/frame. α-slider `[0.05,0.30]` — **erupts at α≥0.26** (checkerboard), marginal at 0.25 (stalls); convergence demo capped at α≤0.24. von Neumann: g=1−8α at p=q=π → −1 at 0.25.
- **Worked:** nodes 2,10,4 → neighbor avg 3, Δu=2+4−20=−14 (peak), one relax `10+0.2(−14)=7.2`; iterate → 3 (Δu=0).
- **Predict:** "Repeatedly replace each point by a touch toward its neighbor-average, edges pinned. After many steps?" → the unique smoothest field matching the edges — a **harmonic function** (Δu=0 everywhere). You watched relaxation solve Laplace.
- **Misconception:** "The Laplacian measures slope." → No: slope is ∇u (first deriv); Δ is second-order = concavity/curvature = how far you differ from your surroundings' average. A straight ramp has huge slope but Δu=0. Why: diffusion ignores tilt, shaves CURVATURE.
- **Deeper:** centered 2nd difference O(h²) Taylor; von Neumann α≤¼(2D)/½(1D), numerically verified (0.25 marginal, 0.26 blows) — the SAME bound governs FTCS heat next; Dirichlet-energy E=½∫|∇u|² with −Δu its gradient → heat = steepest descent on roughness; coordinate-free Δ=div grad=trace Hessian, mean-value property → maximum principle (foreshadows Laplace card).
- **Cross-links:** `whatis`, `bigthree`. **Glossary:** Laplacian, harmonic, von Neumann analysis, boundary condition.

### 03 · `bigthree` — One operator, three fates · *Same bump, same Laplacian — wire it to time three ways, get three universes* · **indigo** · ★ ANCHOR
- **Insight (the payoff):** identical bump, identical Δ. Change only how Δ meets time. uₜ=Δu (heat): RELAX → smoothing, irreversible, arrow of time. uₜₜ=Δu (wave): ACCELERATE → overshoot, split into L/R movers, ring forever, reversible, energy-conserving. Δu=0 (Laplace): no time, you ARE the average. First deriv relaxes, second oscillates, zero is equilibrium.
- **Headline:** `\src{\uu{u}_{\tt{t}}=\lap{\Delta}\uu{u}}\text{ heat · relax}` · `\wv{\uu{u}_{\tt{tt}}=\lap{\Delta}\uu{u}}\text{ wave · accelerate}` · `\eqm{\lap{\Delta}\uu{u}=0}\text{ Laplace · you ARE the neighbors}`.
- **Interactive — three synced N=120 rods (or one + mode toggle) running the SAME initial Gaussian bump under heat/wave/Laplace, with live stability dials.** HEAT (orange→rose): slumps & flattens. WAVE (sky): instant ½-amplitude split, reflects off pinned ends, rings. LAPLACE (emerald): relaxation counter → straight-line 1D harmonic equilibrium. Each panel shows its stability number (heat r, wave Courant C) green/rose. "Push it unstable" button to watch the checkerboard erupt.
- **Verified scheme:** HEAT FTCS `u += r(u_{i+1}−2u_i+u_{i-1})`, **r=0.40**, 6 steps/frame (stable ≤½). WAVE leapfrog `uⁿ⁺¹=2uⁿ−uⁿ⁻¹+C²(…)`, **C=0.70**, 4 steps/frame, **from-rest first step = Taylor half-step** `u¹=u⁰+½C²(u⁰_{i+1}−2u⁰_i+u⁰_{i-1})` (NOT u_old=u — RISK 2). LAPLACE Jacobi α=0.20, 3 sweeps/frame to residual <1e-4. Pinned Dirichlet ends; d'Alembert split = exactly ½ (verified 0.4999).
- **Predict:** match each to its destiny (melts to flat · splits into two ringing travellers · freezes into smoothest field). → uₜ→MELTS; uₜₜ→SPLITS; no-time→FREEZES. Same "neighbors minus you" read as velocity / acceleration / balance.
- **Misconception:** "Three unrelated equations to memorize." → SAME operator Δ wired to uₜ / uₜₜ / 0. Why: that's what makes Fourier trivial — Δ sin kx=−k²sin kx, so each becomes the same family of one-mode ODEs with time-side e^{−k²t} / cos kt / frozen.
- **Worked:** f=sin(πx), Δsin(πx)=−π²sin(πx). Heat → e^{−π²t}sin(πx), e^{−π²}≈5.2e-5 after 1 unit (gone). Wave → cos(πt)sin(πx) (rings forever). Laplace → forces a=0, equilibrium u≡0.
- **Deeper:** the mode-by-mode argument (the Fourier card formalizes it); finite vs infinite speed (d'Alembert vs heat-kernel infinite speed); energy bookkeeping (wave E conserved, heat Dirichlet energy strictly decreases); classification discriminant B²−4AC sorting parabolic/hyperbolic/elliptic with their schemes' bounds (r≤½, C≤1 von-Neumann-verified).
- **Cross-links:** `laplacian`, `whatis`. **Glossary:** heat/wave/Laplace's equation, FTCS, Courant number, CFL, d'Alembert, parabolic/hyperbolic/elliptic.

### 04 · `classify` — Parabolic, hyperbolic, elliptic · *The same names as the conic sections — for the same algebraic reason* · **violet** · not anchor
- **Insight:** the discriminant B²−AC of the second-order part decides a PDE's character — identical algebra to the conics. The sign is not a mnemonic: it's how Δ's wiring to time shows up as one number.
- **Headline:** `A\uu{u}_{xx}+2B\uu{u}_{xy}+C\uu{u}_{yy}+\dots=0` · `\lap{B^2-AC}\begin{cases}<0 & \text{elliptic (Laplace)}\\=0 & \text{parabolic (heat)}\\>0 & \text{hyperbolic (wave)}\end{cases}`.
- **Interactive — DiscriminantDial (pure SVG, no solver):** a −1…+1 axis with three bands (emerald/orange/sky) and three fixed PDE pins (Laplace −1, heat 0, wave +1). Drag a marker → a 220×140 inset conic morphs ellipse→parabola→hyperbola. A 3-column character table (info speed / reversibility / smoothing / data type / characteristics) lights its active column.
- **Verified scheme:** conic `A x²+2Bxy+Cy²=1` with **A=1, B=0, C=−s**, dial `s∈[−1,1]` ⇒ B²−AC=s exactly. s<0 ellipse (sample 96 pts), |s|<0.04 degenerate parabola polyline, s>0 hyperbola (two branches via cosh/sinh, 48 pts each). All recompute synchronously on pointermove (~300 pts). Pins static. Verified: Heat(1,0,0)=0, Wave(1,0,−1)=+1, Laplace(1,0,1)=−1.
- **Predict:** "Heat has a FIRST time-derivative, wave a second. Which lands on the boundary (disc=0)?" → **Heat.** Classification sees only the principal (highest-order) part: heat's is just uₓₓ (A=1,B=0,C=0) → 0, parabolic. The missing time-derivative is literally what moves heat to the boundary.

### 13 · `cfl` — Stability & the CFL condition · *Why your simulation exploded: explicit schemes have a speed limit, and a Fourier mode breaks first* · **rose** · ★ ANCHOR
- **Insight:** an explicit step is a gamble — guess the future from present neighbors. Step too boldly and one Fourier mode's error self-multiplies into a screaming checkerboard. - **Predict:** "The FNO FFTs the field, multiplies each mode by a learned weight, FFTs back. Where have we seen 'transform to Fourier, scale each mode, transform back'?" → **Exactly how we solved heat and wave.** Diagonalizing Δ turned each PDE into one ODE per mode — multiply mode k by e^{−k²t} (heat) or cos(kt) (wave), sum back. The FNO keeps that skeleton but makes the multiplier LEARNED. The spine's trick is the architecture.
- **Misconception:** "A network trained on one PDE has 'learned the PDE' and solves new instances free." → A vanilla PINN fits ONE solution of ONE instance — change the data and you retrain. What generalizes is a neural OPERATOR (FNO): trained on many (input, solution) pairs to approximate the solution map, so a new input is one forward pass. Why: a PINN parametrizes a single function; an operator parametrizes a map between function spaces.
